# Game Searcher

A game search web app built to practise JavaScript, API integration, and front-end development.

## Features

- Search for games
- Browse games by category
- View game information
- Responsive interface

## Technologies

- HTML
- CSS
- Bootstrap
- JavaScript
- REST API
